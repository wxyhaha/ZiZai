## 已知风险与待决事项

0. **完整字体须保留原字体全部字符与字形（已确认，待实现）**。现有 GB2312 范围仍是旧实现；后续须保留原有排版与可变轴能力并做转换前后完整性核验，见 ADR-015。首页独立展示子集不改变这一要求。

1. **字体子集需要随内容更新重建**。脚本已改为用 glob 从源码提取字符
   （新增组件/文案会自动纳入），但**仍需手工运行** `npm run fonts:build`。
   后续可加 prebuild 校验：把源码字符集与 `scripts/font-subset-report.json` 对比，
   不一致就让构建失败。
2. **汇文明朝体缺「楯」（U+696F）**。《项脊轩志》「旧时栏楯」会回退到
   系统宋体/思源宋体。这是原字体本身没有该字形，完整字体策略也解决不了。
   界面与文档都已就此事说明。
3. **汇文明朝体为 2021 年版本**。仓库 README 提到原作者后续发布了新的汇文系列，
   另有社区成员用扩散模型补了 1.6 万缺字。知乎页面返回 403 无法核对来源与授权，
   待能验证后可升级。
4. **朱雀仿宋缺「○」字形**（U+25CB），已在报告中记录；会回退到思源宋体。
5. **竖排标点**依赖浏览器原生 `text-orientation: mixed`。已在 Chromium 下放大目视确认，
   但引号、省略号、破折号在 Firefox / Safari 上仍有差异，需要逐项截图核对。
6. **未做端到端测试**，交互回归目前只有单元测试覆盖。
7. **阅读页 JS chunk 190 kB（gzip 79 kB）**，主要是 Reka UI 的 Dialog 与 Slider。
   只在进入赏字时加载，首页不受影响；若后续要压，可评估按面板动态 import。
