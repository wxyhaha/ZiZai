# 字在 ZiZai — 设计系统与交互规范（v0.1）

> 性质：设计提案，不是已经上线的产品。基于 2026-11-02 的两页面极简方案。

## 1. 产品定位与原则

- 产品名称：字在 / ZiZai
- 副标题：中文古风字体与排版艺术
- 核心陈述：字有风骨，自在其间。
- 结构：仅两个一级页面：首页、赏字。其他功能通过浮层、抽屉、局部切换实现。
- 核心体验：从字体到文稿再到版式，保持用户在一个视觉空间里阅读和试验。
- 设计气质：极简、含蓄、留白、纸本感、真实字体优先。
- 不做：山水画背景、密集梅竹花纹、厚重卷轴边框、伪古董质感、繁复古风按钮、夸张动效、需要滚动进入下一屏的首页。

## 2. 导航与页面

### 首页 `/` 或 `/home`
- 100dvh 单屏完整舞台，导航 + 主视觉 + 底部辅助入口一屏内呈现。
- 只出现：Logo、一级导航（首页/赏字）、汉字缓慢下落、主标题、Slogan、主 CTA「入字间」、少量辅助入口。
- 首屏不通过下滚触发页面切换。文字落下是背景层，pointer-events:none；进入赏字必须通过明确按钮/导航。
- 窄屏可缩小标题/收纳链接，不应水平溢出；极短屏幕允许内部微调布局，但不设计“下一屏”。

### 赏字 `/studio`
- 顶部：字体选择、古文选择、横竖排切换。
- 中央：单个可阅读画布/书页；页面内容比工具界面更醒目。
- 右侧：垂直细工具栏。字体、文选、版式、排版、题写、对照、收藏均以 drawer/popover/局部模式实现。
- 底部：上一篇/下一篇、文本字号调整（作为快捷操作）。
- 正文内部滚动；切换字体时尽可能保留滚动位置或明确重定位规则。
- 移动端右侧工具栏改底部工具栏，抽屉改底部 sheet。

## 3. 设计变量（初版）

| Token | 值 | 用途 |
|---|---|---|
| `--paper` | `#F7F4EC` | 页面主背景 |
| `--paper-deep` | `#EFE8DB` | 纸张层次 |
| `--reading-paper` | `#F6F1E7` | 阅读画布 |
| `--ink` | `#322E2A` | 主要文字 |
| `--muted` | `#897E70` | 次级文字 |
| `--line` | `#DFD6C8` | 细边框分割线 |
| `--accent` | `#9A5548` | 朱砂色按钮/高亮 |
| `--ui` | `#FBF9F4` | 弹层背景 |

- 字体：界面采用易读黑体；展示字体尽量使用经过授权核实的具体字体。设计稿中的系统字形仅用于视觉占位。
- 主要标题：桌面端 76–152px 响应式；移动端 56–80px；整体字重中等。
- 阅读标题：32–40px；正文约 18–23px；阅读行高通常 1.9–2.3，可调。
- 边框：1px 细线；圆角 4–7px；背景纸张纹理需肉眼不明显，不能影响阅读对比。
- 留白：8px 基准间距与 8/12/16/24/32/48/64 等阶梯，实际可局部微调。

## 4. 交互功能矩阵

| 功能 | 首版载体 | 首版内容 | 后续扩展 |
|---|---|---|---|
| 字体图鉴 | 字体选择 drawer | 字体预览卡、名称、简短标签 | 过滤、授权、更多字体 |
| 古文选集 | 文稿选择 drawer | 3–5 篇精选古文 | 分类、全文检索 |
| 横竖排 | 顶部切换按钮 | `horizontal-tb`、`vertical-rl` | 特殊标点与注释适配 |
| 版式模板 | 简单切换 / drawer | 横排、古籍竖排 | 册页、对联、题签 |
| 排版参数 | drawer | 字号、行高 | 字距、宽度、配色、边距 |
| 自定文字 | drawer | 输入文本，替换预览 | 文本模板和持久化 |
| 字体对照 | 预览区域临时分屏 | 两款字体相同文本 | 同步滚动、差异放大 |
| 收藏笺 | drawer | 本地收藏字体+作品+布局参数 | 可导入导出 JSON |
| 导出 | 后续 | 不作为首版硬性要求 | PNG / SVG / PDF 评估 |

**交互约束：** 同时只展开一个主要抽屉；选项改变后预览即时更新；ESC 能关闭面板；抽屉打开要有焦点管理和键盘可达性；重要操作不可只靠 hover；所有图片导出承诺必须经过实际测试。

## 5. 竖排技术约束

- 使用 CSS `writing-mode: vertical-rl` 和 `text-orientation: mixed`，不是把整个文本容器旋转 90 度。
- 古文原句、标点和段落需保留结构。对于特殊标点、引号、注释、分页，采用逐项测试。
- 竖排横向滚动的方向与滚动条行为需跨浏览器验证，不允许正文被截断。
- 版式模板数据化，不将文本内容与模板逻辑耦合在一起。

## 6. 动画

- 首页文字：小数量、随机位置/时间、慢速自上而下、轻微水平漂移、低透明度。
- 动画层不遮挡 CTA，不响应指针事件；手机降低数量；支持 `prefers-reduced-motion`。
- 避免持续重绘昂贵属性；优先 transform/opacity；以实际设备 FPS 观察为准。

## 7. 响应式断点参考

- 桌面 ≥ 1024px：完整顶部导航、中央阅读区域、右侧细工具栏。
- 平板 768–1023px：降低侧栏宽度，阅读区优先。
- 手机 ≤ 767px：首页内容压缩为单屏；赏字操作改为紧凑顶部选择 + 底部工具条 + bottom sheet。
- 短屏用户：先减少非关键装饰，再调整主标题尺寸，最后视情况允许阅读页内部滚动。

## 8. 可访问性与工程质量

- 语义按钮，明确可见的键盘焦点；对话框处理 focus trap、Esc、恢复焦点。
- 色彩对比度检查，不能用低对比度装饰字承载关键信息。
- 自定义文本默认做纯文本渲染，禁止未经安全控制的 innerHTML 注入。
- 文章与字体都以数据层管理，提供来源、授权、作者、描述、字符覆盖等元信息。
- 字体 WOFF2/按需加载/子集策略必须结合真实汉字覆盖需求，不能为了减小体积破坏用户输入体验。
- 开发时记录字体版权依据；不自动宣称“可免费商用”，不重新打包上传授权不明的字体。

## 9. 验收口径

1. 首页无长滚动内容、无第二屏；点击「入字间」准确进入赏字。
2. 选择任意已收录字体，预览确实换字体（可通过 computed style 检查）。
3. 选择任意古文，正文/作者/标题正确更新。
4. 横排和竖排均能完整阅读指定长文本，不截断，标点基本正确。
5. 抽屉/选择器键盘操作、关闭、焦点恢复符合常见无障碍规范。
6. 320、375、768、1280、1440px 宽度下无水平溢出、按钮无遮挡。
7. 关闭动画偏好时没有持续落字运动。
8. 构建成功、资源路径正确，README 可复现启动。

## 10. 设计稿说明

- `index.html`：可直接在浏览器打开的零依赖交互原型，样式和互动独立于正式 Vue 工程。设计模拟字体使用本地系统字体，**不保证与真实字体字形一致**。
- `homepage-editable.svg`：首页分层矢量稿。
- `reading-editable.svg`：赏字阅读页分层矢量稿。
- `font-selector-editable.svg`：字体抽屉分层矢量稿。
- 对应 PNG 仅用于快速查看。SVG 可以导入 Figma、Illustrator 等继续编辑；**不是原生 Figma 项目**，字体渲染依赖目标设备字体。
